# 検証範囲画面の要件

## スイートの結果から製品の検証範囲を読む

- 製品担当者は、概要から「検証範囲」を開き、どのスイートの何回目を見ているかと、まだ確かめられていない振る舞いの名前を読める。
- ケース未設計、今回未判定、明示的な不合格を識別できる。対象のすべてを確認した回では、その画面で確認を終えられる。
- 構成図の要素・接続から対応する振る舞いを選び、受入条件とその回の確認項目を照合できる。実行結果から来た場合は元の回へ戻れる。
- キーボードとタッチ幅で同じ順序をたどれる。構成図・ケースの対応が未登録、証跡が不適格、実行中の場合は、それぞれの状態が分かる。
